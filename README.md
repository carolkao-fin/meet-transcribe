# 🎙 MeetTranscribe

> 免費 AI 會議轉錄與分析工具｜Groq Whisper + Llama 3.3 + Streamlit

上傳音訊或即時錄音 → 自動轉錄逐字稿 → 指定發言者 → AI 生成會議摘要、行動項目與主題標籤，全程使用 Groq 免費方案，一個 API Key 搞定所有功能。

---

## 功能總覽

### 音訊輸入

| 功能 | 說明 |
|------|------|
| **上傳音檔** | 支援 mp3 / wav / m4a / aac / ogg / flac / webm，最大 100 MB |
| **即時錄音** | 在瀏覽器內直接錄音後送出（需 Streamlit ≥ 1.31） |
| **自動轉檔** | 不支援的容器（如 raw .aac）自動以 ffmpeg 轉成 mp3 再上傳 |
| **大檔分割** | 超過 24 MB 的音訊自動切成 8 分鐘片段分批轉錄，時間戳自動對齊 |

### 轉錄（Groq Whisper Large v3）

- 支援語言：**自動偵測 / 中文 / 英文**
- 逐段輸出，每段帶有精確的起始時間戳（`HH:MM:SS`）
- 中文輸出自動轉換為**繁體中文**（opencc s2twp），並補上正確標點符號
- 轉錄完成後自動存入瀏覽器歷史記錄

### 即時口譯（「即時錄音／口譯」分頁）

演講、研討會現場用：聽講者說話，Groq Llama 依場景即時翻譯，畫面上原文與譯文並排。

| 功能 | 說明 |
|------|------|
| **即時翻譯** | 按「開始聆聽」後每說完一段就翻譯；也可直接輸入或貼上文字 |
| **講者語言** | 預設**自動偵測**（Groq Whisper，任何語言、中英夾雜皆可，字幕約慢 5–10 秒）；也可指定語言，改用瀏覽器語音辨識，字會邊講邊出現 |
| **翻譯成** | 繁體中文、English、**自動（中文↔英文互譯）**、日本語、한국어、简体中文 |
| **上傳簡報** | 上傳講者的 `.pptx` / `.pdf`，自動整理主題與專有名詞，用來提示語音辨識、修正聽錯的名詞並統一譯法 |
| **專有名詞對照表** | 可編輯的表格；可匯入 Excel／CSV（附範例檔下載）；AI 會邊聽邊學新名詞，學到的可修改、停用、刪除；可下載成 Excel 下次沿用 |
| **場景判斷** | 可自行填寫場景，也會依內容自動判斷 |
| **儲存** | 每場口譯自動存入「歷史記錄」；可下載 Word 對照表、CSV、純文字，皆同時包含原文與譯文 |

注意：請使用電腦版 **Chrome 或 Edge** 並允許麥克風；自動偵測模式會使用 Groq 音訊額度（免費方案每小時 7,200 秒）。

### 逐字稿編輯

- 每段可重新指定發言者（最多 6 位）
- 可直接編輯文字內容（修正術語、公司名稱等）
- 時間軸時間碼顯示於每段旁邊

### AI 分析（Groq Llama 3.3 70B）

分析結果包含四個部分：

| 區塊 | 說明 |
|------|------|
| **Meeting Summary** | 2–4 個小節，每節含概述段落與 3–6 條要點（標明發言者） |
| **Topics** | 2–4 個主題標籤 |
| **Action Items** | 依負責人分組的行動任務清單 |
| **Corrected Transcript** | AI 修正後的逐字稿（術語、人名、公司名） |

輸出語言：逐字稿含中文則輸出**繁體中文**（含 AI 修正逐字稿），否則輸出**英文**。

### 下載與匯出

所有產出檔案均包含 `[HH:MM:SS]` 時間軸標示：

| 下載項目 | 格式 | 說明 |
|----------|------|------|
| **下載會議記錄** | `.txt` | 摘要 + 行動項目 + 帶時間軸的逐字稿 |
| **下載 JSON（可重新載入）** | `.json` | 完整資料，可於歷史記錄分頁重新載入 |
| **下載逐字稿** | `.txt` | 純逐字稿，每行格式：`[HH:MM:SS] 發言者: 內容` |
| **下載原始錄音** | 原始格式 | 上傳或錄製的音訊檔案 |

### 歷史記錄

- 儲存於瀏覽器 **localStorage**，重新整理或關閉視窗後仍保留
- 可查看、刪除過去的紀錄
- 支援上傳 `.json` 檔案重新載入分析結果
- 未完成 AI 分析的記錄（純逐字稿）亦可單獨儲存與下載

## 快速開始

### 1. 申請 Groq API Key（免費）

前往 [console.groq.com](https://console.groq.com)，以 Google 帳號登入後即可取得 API Key（`gsk_...`）。

### 2. 部署方式

**Streamlit Cloud（推薦，無需本地安裝）**

1. Fork 本儲存庫
2. 前往 [streamlit.io/cloud](https://streamlit.io/cloud) 連結 GitHub，選擇此 repo 部署
3. 在 App 設定中加入 Secret（非必要，也可在 UI 中手動輸入 Key）

**本地端執行**

```bash
# 安裝 Python 依賴
pip install -r requirements.txt

# 安裝系統依賴（大檔分割所需）
# Ubuntu/Debian
sudo apt-get install ffmpeg
# macOS
brew install ffmpeg

# 啟動
streamlit run app.py
```

### 3. 使用流程

```
輸入 API Key（側邊欄）
    ↓
填寫會議標題、語言、發言者姓名
    ↓
上傳音檔 / 即時錄音 → 點擊「開始轉錄」
    ↓
在逐字稿編輯區指定每段發言者、修正文字
    ↓
點擊「AI 分析」生成摘要與行動項目
    ↓
下載 .txt 或 .json，或在歷史記錄中管理
```

## 技術規格

| 項目 | 說明 |
|------|------|
| 轉錄模型 | `whisper-large-v3`（Groq 託管） |
| 分析模型 | `llama-3.3-70b-versatile`（Groq 託管） |
| 前端框架 | Streamlit 1.31+ |
| 音訊處理 | ffmpeg / ffprobe |
| 中文轉換 | opencc-python-reimplemented（簡體→繁體，s2twp） |
| 持久化儲存 | 瀏覽器 localStorage |

### Groq 免費方案限制

| 資源 | 上限 |
|------|------|
| 音訊轉錄 | 7,200 秒／小時 |
| 分析 Token | 12,000 TPM |
| 單檔大小 | 25 MB（超過自動分割） |

超限時 App 會顯示友善的中文錯誤訊息並說明等待時間。
